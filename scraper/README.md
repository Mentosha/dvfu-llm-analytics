# Подготовка датасета

## Источники данных

### `synthetic.py` — синтетический генератор

Генерирует 30 (или сколько укажешь) реалистичных описаний товаров в стиле Dewu/Poizon:

```bash
python -m scraper.synthetic --output pipeline/example_input.csv --count 30
```

Получаются разные товары (кроссовки, одежда, сумки, аксессуары) с шумом в заголовках:
смесь китайского/английского/русского, разные валюты (`¥1499`, `1499 CNY`, `1499元`, `RUB 19000`, `$210`),
неполные описания, разные комбинации цвет/размер/материал. Воспроизводимо через `--seed N` (default 42).

### `dewu.py` — реальный парсинг (best-effort)

```bash
python -m scraper.dewu --output data/dewu_raw.csv --queries "air jordan" "yeezy"
```

У Dewu подпись запросов и гео-блокировка. Модуль пытается забрать данные через `__NEXT_DATA__` веб-каталога, но может вернуть 0 строк.

Если `dewu.py` не возвращает данных — **используй `synthetic.py`**: смысл проекта в пайплайне в LLM, а не в скрапере.

## Формат на выходе

```csv
id,raw_title,raw_description,raw_price,source_url
1,...,...,...,...
```

Этот CSV — вход для `pipeline/extract.py`.
